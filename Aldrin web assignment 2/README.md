# FISAT CSE Department Website

A simple, multi-page college department website built with HTML, CSS and a little JavaScript.
Made for the Web Programming assignment (S7 CSA, FISAT).

**Author:** Aldrin Baiju | Roll No. 20 | Reg. No. FIT23CS020

## Pages

| File | Content |
|------|---------|
| `index.html` | Home: hero, highlights, programmes |
| `about.html` | Overview, vision, mission, notice board |
| `academics.html` | Programmes, subjects offered, admission steps |
| `faculty.html` | Faculty table (sample data) |
| `facilities.html` | Laboratories and campus life |
| `contact.html` | Student enquiry form, contact details, FAQs |

Supporting files: `style.css`, `script.js`, `images/logo.png`.

## Run

Open `index.html` in any web browser. No build step is needed.

## Notes

All faculty names, phone numbers and e-mail addresses are sample data for an academic exercise.
